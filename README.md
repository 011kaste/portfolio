# Alessandro Castellani · Interactive Portfolio

Static site, served with GitHub Pages at https://011kaste.github.io/portfolio/

- `index.html`: the page (interactive interview + PDF viewer)
- `assets/portfolio.pdf`: the full portfolio. Replace this file to update the PDF, nothing else needs to change.
- `assets/*.jpg`: the idle frame and the three speaking frames
- Contacts: the Nokia on the table (click it, press `C`, or the C hint). Edit the `contacts` array at the top of the script in `index.html`.
- `assets/nokia.png` (optional): a transparent photo of the phone. If present it replaces the drawn placeholder on the table automatically.
- `assets/favicon.svg`: tab icon

To publish: Settings → Pages → Source "Deploy from a branch", branch `main`, folder `/ (root)`.
